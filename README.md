# Docker ML Practical

## Aim
To deploy a Machine Learning application using Docker.

## Dataset
Iris Dataset

## Algorithm
Random Forest Classifier

## Technologies
- Python
- Flask
- Scikit-learn
- Joblib
- Docker

## Application Features
- Train a Machine Learning model
- Save the trained model
- Deploy the application using Docker
- Predict Iris flower categories

## API Endpoints
- GET / : Home
- GET /health : Health check
- POST /predict : Flower prediction
